# Hostbound 开发记录

这是开发时的计划和进度记录：分了哪几个阶段、每个阶段做成什么样、怎么做的、为什么这么做。2026-10-14 起草，每做完一个阶段在那一节开头补上进度。文中的「你」「宿主」都是指作者本人。

**这次要做**：语音播报、按住说话、操作可视化、看屏幕回答、系统任务与主动提醒、长期记忆、技能，以及把设计稿里还没做的页面补上。

**这次不做**：直播联动；换视觉模型（DeepSeek V4.1 Flash 自己能看图）。

## 一、顺序和规模

| 阶段 | 内容 | 规模 | 做完你能看到 |
| --- | --- | --- | --- |
| 1 | 系统的声音 + 按住说话 | 中 | 「叮」一声后系统开口说话；按住一个键说话，松开就执行 |
| 2 | 看得见的操作 + 看屏幕回答 | 中 | 它操作哪个软件，哪个软件就亮扫描框；点哪里，哪里冒光圈；任务分步骤显示进度；能回答「系统，看看我屏幕上这是什么」 |
| 3 | 多页面面板 + 设置、记录、日志 | 中 | 面板能翻页；设置不用再手改配置文件；能翻历史对话，能查系统做过的每个操作；重启后能接着聊 |
| 4 | 系统任务与主动提醒 | 中 | 「半小时后提醒我喝水」会生成一个【限时任务】倒计时；下载完成、电量低、渲染完了，它会主动报告 |
| 5 | 长期记忆（先调研） | 大 | 系统记得你的习惯、常用路径、正在做的项目；记忆页里每条都能看、改、删 |
| 6 | 技能（先调研） | 中 | 把固定流程教给系统，一句话跑完整套 |

**为什么按这个顺序**：
- 1、2 最显眼，又不依赖别的部分，先做完整体感觉就变了。
- 3 是后面的地基，任务、记忆、技能都需要自己的页面和存盘。
- 5、6 要先调研，放在后面不耽误前面的进度。

## 二、每个阶段怎么推进

1. **先出样子给你看**：界面出设计稿，跟之前的系统设计稿同一套风格；声音出试听样本。
2. **你确认后再改程序**。
3. **自测**：每个阶段都加对应的自动测试，现有的测试也要全部通过。
4. **你试用**，没问题再进下一阶段。

记忆和技能这两个阶段，写代码前先调研：去 GitHub 读星标多、还在维护的同类项目，把它们的做法写成一份对比给你。方向定了再开发。其他阶段如果碰到现成的好轮子，也是先查再自己造。

## 三、各阶段细节

### 阶段 1 · 系统的声音 + 按住说话

> **进度（2026-10-14）：已完成。** 选定音色 D「中性机械系统」。显卡版用 faster-qwen3-tts 加速，约 0.5 秒出声；CPU 备用是 ZipVoice。按住说话用鼠标靠前的侧键或右 Ctrl（原定右 Alt，因为单按 Alt 会激活很多软件的菜单栏，所以改了）。默认最多念 60 字。

**做成什么样**
- **音色**：用你电脑上已经装好的 Qwen3-TTS「音色设计」模型，按一段文字描述生成几个候选。描述比如「冷静、略带电子感的年轻女声，语速偏快，没有情绪起伏」。你挑一个，我把它固定下来，以后每句话都是这个声音。这是原创音色，开源时没有版权麻烦。
- **说什么**：只念要紧的内容，包括结论、【】里的关键结果、授权请求和提醒。长段落、代码、文件路径、网址都不念，只显示在面板里。
- **系统音效**：声音再过一层电子滤波和轻微混响，听起来像「系统音」。先「叮」一声再开口，面板里的文字跟着声音一个字一个字出现。
- **反应快**：常用句提前生成好，播放没有延迟，比如开机问候、「宿主，请下达指令」「检测到高危操作，请授权」「任务完成」。临时的回复按句子生成，模型写完一句就念一句。
- **不会自己听自己**：系统说话时暂停听指令，但「系统停止」随时能打断它。用音箱外放这样就够了，戴耳机效果最好。
- **按住说话**：按住一个键说话，松开就当作一句指令发出，不用喊唤醒词。默认用鼠标侧键，可以在设置里改。直播时最稳，不怕误唤醒。
- **静音开关**：托盘菜单里加一个。

**怎么做**
- 后台起一个本地语音服务，用 `D:\Qwen3-TTS` 现成的 Python 环境。系统把要念的句子发给它，拿回音频在面板里播放。
- 如果显卡被占满（打游戏、直播编码）或者语音服务没起来，就退回 CPU 语音。CPU 语音用的是 sherpa-onnx，耳朵已经在用它，不过要另外下载一个中文语音模型，大约 100MB，下载前先问你。CPU 语音也不行时，就只显示文字。
- 按住说话用 uiohook-napi 来同时监听全局按键的「按下」和「松开」。Electron 自带的快捷键只能知道键被按下，不知道什么时候松开。

**借鉴**
- QwenLM/Qwen3-TTS（13.8k★）：模型和推理。
- k2-fsa/sherpa-onnx（15k★）：备用语音。
- morettt/my-neuro（1.4k★）：开源的桌面 AI 伴侣，看它怎么处理「边说边听」和「被打断」。

**风险**：1.7B 模型大约要占 4–6GB 显存，以实测为准。你的显卡是 8GB 的 4070 笔记本版，跟游戏、直播编码同时用可能会抢显存。实测不行的话，换成小一号的 0.6B 模型（需要下载，到时先问你），或者用 CPU 语音。

### 阶段 2 · 看得见的操作 + 看屏幕回答

> **进度（2026-10-14）：已完成。** 扫描框、系统光标、点击光圈、输入字幕、键帽、步骤条、操作视图、全屏通知 / 角落小提示、看屏幕回答、不抢焦点、申请接管前台都已上线。效果画在每块屏幕各自的透明窗口里（不用时自动藏起）。调 Windows 用 koffi（宿主同意下载）。Open Computer Use 报的元素坐标是相对窗口左上角（含隐形边框）的，已按窗口实际位置换算。对比测试 Cua Driver（DeepSeek Harness 实验性电脑操控用的引擎，MIT）放到阶段 2 之后。
>
> **补充（2026-10-15）：接上 Cua Driver 当主引擎。**
>
> - **对比结果**：Cua 读 OBS 用 0.13 秒、能操作 127 个元素，Open Computer Use 要 1.3 秒、50 个；Obsidian 这类 Electron 应用 Cua 能读出 300 多个，Open Computer Use 只有 10 个；Word 反过来是 Open Computer Use 读得多。
> - **两个引擎怎么挑**：都由 `brain/screen.mjs` 管，对大脑只露出一套工具（list_apps / open_app / read_app / click / type_text / press_keys / scroll）。读界面先用 Cua，读出的可操作元素少于 8 个，就再用 Open Computer Use 读一遍，哪个多用哪个。
> - **后台和前台**：Cua 默认只走后台，绝不切前台。软件收不到后台输入时（Chromium / Electron 的按键和滚动），它直接报错，大脑就去申请接管前台。宿主同意后，同样的动作改走前台，做完把焦点还回去。
> - **输入框**：直接填值，后台也能用。
> - **加强授权**：在聊天软件里按回车也要授权。
> - **实测**（只碰测试自己开的窗口）：读、按编号点、按截图坐标点、填中文，都没把目标窗口拉到前台，也没动鼠标。
> - **感知扩展**：Cua 的看图识别扩展有 400MB，每次识别 8～9 秒，含 AGPL 组件，先不装。剪映由宿主手动打开后实测（宿主同意点左侧菜单）：两个引擎都只读出窗口本身（Qt 自绘界面），但后台截图清楚，按截图坐标在后台点「模板」「首页」，页面都能正确切换，不抢焦点、不动鼠标。读一次约 0.26 秒，点一次约 0.14 秒。
>
> 剪映实测踩到的两个坑都已处理：
>
> - **截图编号要新**：按坐标点时，截图编号必须是最近一次调用拿到的，所以读过的窗口不再重新列窗口，编号旧了就先补截一张。
> - **界面接口偶尔忙**：剪映的界面接口偶尔报「busy」，这时 Cua 不会发出任何输入。系统等 0.8 / 2 / 4 秒后补截一张再试，都不行就让大脑稍后再试，或者申请接管前台。
>
> 另外，同一个窗口上 OCU 也读不出更多时，就不再每次白等它。

**做成什么样**
- **扫描框**：系统读取某个软件的界面时，那个窗口外面会亮起一圈扫描框，配一个标签，比如「【扫描中】计算器」。操作网页时，框住的是系统专用的那个 Chrome。
- **点击光圈**：系统每点一下，点击位置冒一个光圈。打字时，旁边飘一行字幕显示输入的内容；按快捷键时显示键帽，比如 Ctrl + S。
- **任务进度**：复杂任务先拆成步骤，面板上方显示「① 打开计算器 ▸ ② 读取界面 ▸ ③ 输入 7+8 ▸ ④ 完成」。当前步骤发光，做完的打勾。
- **全屏系统通知**：任务完成、失败或提醒到点时，屏幕中央弹出一个大号系统通知，几秒后自己收起。设置里可以关掉。
- **操作视图**：把设计稿里的「网页操作」「软件操作」两页做出来。
- **看屏幕回答**：你说「系统，这个报错怎么回事」「看看我屏幕上这是啥」，系统先放一遍全屏扫描线特效，再截图交给 DeepSeek V4.1 Flash 看。回答显示在面板里，开了声音就念出来。截图前会先把系统自己的面板藏起来，免得挡住内容。
- **系统光标**：一个发光的菱形，从核心飞到要点的地方再点，点完飞回来。它只是画出来给人看的，系统其实在后台点，你的鼠标不动。（借鉴 trycua/cua 的「人和 AI 各有各的光标」）
- **不抢焦点**（2026-10-14 加）：Windows 平时会把新开的窗口顶到最前面、抢走键盘。系统开软件时改成在你当前窗口后面打开、不激活；少数软件硬抢到前面，系统马上把焦点还给你刚才在用的窗口。核心旁边弹一句「后台打开了某某」。
- **需要占用前台时先请示**（2026-10-14 加）：遇到后台点不动的软件，系统不直接抢鼠标。先在面板里申请（金色），说明要干什么、大约几秒，并念出来。你说「可以」或点「允许」后倒数 3 秒，屏幕四周亮金边，顶上横幅显示剩余时间。期间你一动鼠标或按 Esc，系统立刻停手、归还控制权。30 秒没回应就当「稍后」。

**跟宿主同时用电脑**：Cua Driver 和 Open Computer Use 在 Windows 上点击用的是无障碍接口或直接发给窗口的点击消息，打字也是直接发给窗口（或者直接给输入框填值），不动真鼠标、不抢键盘；网页通过 Chrome 调试接口操作；命令在后台跑。所以平时你和系统可以各干各的。会冲突的只有三种情况：新开窗口抢焦点（靠「不抢焦点」解决）、两边同时操作同一个窗口（扫描框标出系统在用哪个窗口）、少数只认前台输入的软件（靠「先请示」解决）。

**怎么做**
- 扫描框和光圈的位置：Open Computer Use 读界面时，每个按钮都带屏幕坐标（已经确认过），直接从这里取。网页里的元素位置由 agent-browser 给出，再换算成屏幕坐标。
- 任务步骤：给大脑加一个「更新任务步骤」的小工具。模型开始干活时先列步骤，每做完一步更新一次。
- 截图只在你开口要求时才截，不会偷偷看。
- 不抢焦点：开软件前记下你在用的窗口，用「显示但不激活」的方式打开新窗口；发现焦点被抢就还回去。
- 占用前台：给大脑一个「申请占用前台」的工具，你同意后才放开真实鼠标键盘（Open Computer Use 在 Windows 上没有这条路，要另外接一个能模拟真实输入的办法，开发前先查现成方案）；接管期间用按住说话那套全局按键监听盯着，你一动就停。

**借鉴**
- Sylinko/Everywhere（6.3k★）：一个能看屏幕的桌面 AI 助手。
- 任务步骤参考 Claude Code、pi 生态里的待办清单做法。

### 阶段 3 · 多页面面板 + 设置、记录、日志

> **进度（2026-10-15）：已完成。** 设计稿 `design/phase3.html`，宿主全部按默认，只改了一条：不按 4 小时断开，改成**一个窗口一直聊**。
>
> - **无限对话**：做法参考 [DeepSeek Bot](https://github.com/FeiZhuLulu/DeepSeek-Bot)（DeepSeek Harness 的社区插件，Apache-2.0，约 2k 星）。它是一个窗口一直聊，上下文快满时让模型写交接摘要、最近的原样保留，旧内容进全文索引可以搜。
>   - 我们直接用 pi 自带的会话存盘和自动压缩（DeepSeek Bot 的致谢里也写了借鉴 pi）。对话存在 `data/sessions`，重启后接着最近一次。
>   - 上下文超过预算（默认 12 万 token，设置里能调）就压缩。pi 按「模型窗口 − reserveTokens」判断，所以 reserve = 窗口 − 预算。
>   - 大脑多了 `search_chat` 工具，能翻以前对话的原文。「换个话题」只清大脑的上下文，面板上还是一个窗口，往上翻得到以前的。
> - **面板**：页签「对话 · 记录 · 日志 · 设置」。翻到后三页时面板加宽到 760×560（大小单独记住），回到对话页变回原来大小。说「系统，打开设置」之类直接翻页，不经过大脑。
> - **对话页**：往上滚从存盘里一页页读回以前的对话；隔 30 分钟以上插一条时间；换话题处有分隔线。
> - **记录 / 日志**：任务记录在 `data/history.jsonl`，系统日志在 `data/logs/日期.jsonl`，保留 30 天。日志页实时刷新。
> - **设置**：九类（听觉、声音、大脑、操作、安全中心、直播模式、快捷键、外观、关于），改完马上生效，只把跟默认不一样的写进配置文件。
>   - 唤醒词、麦克风、灵敏度改完会自动重启耳朵。
>   - 工具开关、工作目录、禁止名单改完会重新加载大脑，对话照样接着。
>   - 快捷键注册不上会提示并保持原样。
>   - 新增「禁止操作的软件」名单：名单里的软件读都不读。
> - **新手引导**：第一次打开时三步走。老用户自动跳过，可在「关于」里再看。
> - **还差**：添加唤醒词时自动转拼音，要下载 pinyin-pro（MIT，约 950KB），等宿主同意；现在是手写拼音、程序校验音节。

**做成什么样**
- **翻页**：系统面板加页签，可以在「对话 / 任务 / 记忆 / 技能 / 记录 / 设置」之间切换。也可以直接说「系统，打开设置」。
- **设置页**：照设计稿里的「听觉、大脑、安全中心、直播模式、快捷键、外观」几页来做。改完立即生效，需要重启的项会提示。以后不用再手改配置文件。
- **任务记录**：按天列出你下过的指令、系统做了什么、结果是什么。能搜索，点一条就能接着那次对话继续聊。
- **系统日志**：系统执行过的每个操作都会留档，包括运行的命令、点过的按钮、打开的网页和授权记录。出了问题能查清楚它到底干了什么。
- **对话存盘**：重启系统后还能接着之前的对话聊。
- **其他页面**：把设计稿里的「新手引导」「关于系统」也做出来。

**怎么做**
- 对话改用 pi 自带的会话存盘。现在对话只存在内存里，一重启就没了。
- 所有个人数据（对话、日志、任务、记忆、技能）统一放进项目里的 `data` 文件夹。开源时整个文件夹不上传。

### 阶段 4 · 系统任务与主动提醒

> **进度（2026-10-15）：已完成。** 设计稿 `design/phase4.html`，宿主全部按默认；直播用 B站直播姬和抖音直播伴侣。
>
> - **定时任务**（`brain/tasks.mjs`）：结构参考 HKUDS/nanobot 的 cron，分一次（at）、每隔多久（every）、按规则重复（cron）三种；下次时间用 croner 10.0.1 算（MIT，宿主同意下载）。
>   - 存在 `data/tasks.json`，关机期间错过的提醒开机补一次，重复的只补最近一次。
>   - 「提醒我…」不花钱；「到点帮我做…」到点排队交给大脑去做，任务记录里标成「定时任务」。
> - **到点提醒**：叮一声（新提示音）、金色全屏通知（直播时换成角落小提示）、念出来，对话里出一张【限时任务】卡，带「知道了」「10 分钟后再提醒」两个按钮。
>   - 能用嘴回答，「过 X 分钟再提醒」的识别规则在 `intent.mjs` 的 parseReminderAnswer。
>   - 等回答的 20 秒里听到别的话，按连续对话处理：先判断是不是对系统说的。
> - **核心下面的倒计时**：一小时内到点的任务才挂，显示最近那个，最后一分钟闪烁。
> - **监测**：参考 OpenClaw 的条件监测。
>   - 宿主让盯的：文件夹来新文件、某个文件生成完、某个程序退出，默认报告一次就撤。
>   - 自带的：下载完成（角落小提示）、电量低（20% / 10%，念出来）、直播检测（直播软件开着或 OBS 日志出现「开始推流」→ 自动开直播模式，停了自动关；宿主手动开的不自动关）。
>   - 「写完了」的判断：不是临时文件、大小连续 5 秒不变。
>   - 程序列表、电量直接调 Windows（koffi），列一次 144 个程序约 7 毫秒。
> - **面板**：新增「任务」页签，分定时任务（倒计时）、正在盯着的、自带的监测（开关）、最近提醒过的；设置 · 直播模式里能改直播软件名单。
> - **唤醒词自动转拼音**：pinyin-pro 3.29.5（MIT，宿主同意下载）。模型把 y、w 也当声母，所以自己拆。
> - 宿主电脑上没装 B站直播姬，名单里先放了 livehime.exe；抖音直播伴侣的程序是 直播伴侣.exe（由启动器拉起）。

**做成什么样**
- **定时任务**：比如「半小时后提醒我喝水」「每天晚上 11 点提醒我睡觉」「明早 9 点提醒我交稿」。说完系统发布一个「【限时任务】补充水分　剩余 29:59」，到点「叮」一声，弹出全屏通知并念出来。
- **任务页**：列出所有进行中的任务和倒计时，点一下或说一声就能取消。关机重启后任务还在。
- **主动监测**：系统盯着一些事，发生了就主动报告。比如：
  - 下载完成（下载文件夹出现了新文件）；
  - 电量低于 20%；
  - 渲染导出完成（导出文件生成了，或者软件进程结束了）；
  - 某个文件夹来了新文件。
- **让它自己设监测**：你说「等这个视频导出完叫我」，系统就自己建一条监测，完成时提醒你。
- **不花钱**：监测和提醒都是规则判断，不调用模型。

**借鉴**
- OpenClaw（392k★）：定时任务、心跳检查、常驻指令的设计。
- HKUDS/nanobot（49k★）：定时任务的实现，代码短，适合读。

### 阶段 5 · 长期记忆（先调研）

> **进度（2026-10-15）：已完成。**
>
> - **调研**：结论在 `docs/research-memory.md`。主流（DeepSeek Bot、OpenClaw、nanobot、Letta，连 Letta 都改了）是 Markdown 文件、小份常驻、按需检索、后台整理、改动留底；向量库或知识图谱派（mem0、Graphiti、MemOS）对单人桌面太重，也不透明。

> - **文件**（`brain/memory.mjs`）：`data/memory/` 下 `宿主.md`（上限 2000 字）、`记忆.md`（上限 4000 字，带「## 目录」）、`主题/*.md`。
>   - 格式用 Agent Memory Repo：一条一行，末尾 `[source: 对话 时间; added: 日期]`。
>   - 每条最多 300 字；拒收密码、密钥、证件号、银行卡号。
>   - 改动记进 `journal.jsonl`，能整次撤销；用记事本改了会自动重新读。

> - **向量**（`brain/vector.mjs`）：硅基流动 `/v1/embeddings`。
>   - 关键词（英文按词，中文按单字和两字一组）和余弦相似度各排一次名，用 RRF 合起来。
>   - 向量缓存在 `data/memory/.index`，同一段文字只算一次；以前的对话在后台慢慢补算。
>   - 出错时按原因暂停一会儿，期间只用关键词。
> - **密钥**：宿主在设置 · 大脑里自己粘，主进程写进 `data/secrets.json`；面板只拿得到「配没配」。也认环境变量 `SILICONFLOW_API_KEY`。
> - **面板**：新增「记忆」页签（分组、每条改删、来源跳回对话、按意思搜、最近改动撤销、开关和状态）；对话里冒紫色的「记忆已更新 · 查看 · 撤销」。

**做成什么样**
- **记得宿主**：比如怎么称呼你、常用软件和文件放哪（「成品视频导出到 D:\成品」）、正在做的项目、你说过的偏好。关掉再开也不会忘。
- **能记能删**：说「系统，记住……」它就记下，说「系统，忘掉……」它就删掉。干活时也会主动记下值得记的事。
- **记忆页**：每条记忆都能看、改、删，还能看到它是什么时候、从哪次对话里记下的。

**初步方向**（调研后再定）

参考 OpenClaw 的分层做法，分成四层：
- **宿主档案**：称呼、偏好、习惯，每次对话都带上；
- **长期记忆**：重要的事实和决定，每次对话都带上；
- **每日记录**：细节，用到时再检索；
- **定期整理**：每天把每日记录里值得留的内容提炼进长期记忆，同时去掉重复和过时的。

所有记忆都是本地的文字文件，人能直接打开看，最透明。

### 加做 · 项目模式

> **进度（2026-10-15）：已完成。** 调研 `docs/research-projects.md`，设计稿 `design/projects.html`，宿主全部按默认：开工前先看计划、计划卡上能换文件夹、干活的默认跟总指挥同一个模型（设置里能换 Claude Code / Codex）、每个干活的一份 git worktree 由总指挥合并、项目文件夹里自动放行、预算 ¥30（八成提醒、用完先问）、一个任务最多 80 轮、同时最多 12 个、做完 = 能启动 + 测试全过 + 首页截图看过 + 评审通过。

- **干活的**（`brain/project-workers.mjs`）：pi 会话（工具 read / write / edit / powershell / ls / find / grep + 问总指挥 + 汇报），授权按 `project-gate.mjs`；Claude Code 用 `claude -p --output-format stream-json`，授权走 PreToolUse 钩子（`tools/project-hook.mjs`，请求文件交给系统去问）；Codex 用 `codex exec --json`（workspace-write 沙箱，能联网装依赖）。后两种最后一行写 `QUESTION:` / `REPORT:`，回答后 resume 接着做。卡住检测：同样的操作和结果重复 4 次。

- 调研里定下来的几条：干活的只跟总指挥说话、不能直接问宿主；智能体的话不算宿主的同意；状态全写成文件；合并一个检查一次；预算、轮数、卡住都有硬上限；小东西一个智能体干。

## 四、费用、隐私、开源

- **费用**：声音、监测、提醒都在本机跑，不花钱。记忆会让每次对话多带一点上下文，每天整理记忆也要调用一次模型，花费都很少。
