设计稿 · 项目模式

在主窗口说「帮我做一个 xx」，总指挥把需求问清楚、写好计划给你过目；你点「开工」以后，它把活分给几个智能体在各自的代码副本里一起干，自己负责合并和检查。主窗口只留一张项目卡，点开是项目页：每个智能体收到的任务、每一步、产出，还有它们之间的通信记录。干活的有问题先问总指挥，总指挥答不了才来问你。调研见 docs\research-projects.md。

通信谁对谁说了什么，按时间排。消息分五种：分派、汇报、提问、回答、合并。干活的之间不直接聊，都经过总指挥，所以这一页就是全部的来龙去脉。

合并每个干活的在自己那份代码副本（git worktree）里干，从不直接动主线。总指挥一个一个合并，合并一个就跑一次构建和测试；网站类再用浏览器打开截图看一眼。

每个智能体最多80 轮同一件事重复 4 次算卡住，退回总指挥重新安排
项目里自动放行项目文件夹里读写、装依赖不问；出了文件夹、危险操作照常问

干活的用谁：默认跟总指挥一样（pi + 同一个模型，用你配好的 key）。也能选这台电脑上装好的 Claude Code、Codex：会用它们自己的账号和额度。每个干活的都是系统拉起来的一个子进程，挂了不影响别的，点「停止」立刻停。

同时最多几个：默认 12 个，可以改成不限。总指挥按活的大小派，小东西一个人干（调研里一个智能体干小项目反而又好又省），不会为了凑数多派。

花费：每个智能体、每个项目实时算钱（按模型的价格表）。预算用完不再派新活，停下来问你要不要追加。

五、文件长什么样

记账网站\ ← 你的项目（一个 git 仓库，主线是总指挥合并好的） web\ server\ docs\ … .hostbound\ ← 项目模式自己的记录（加进 .gitignore） request.md 宿主原话、问答 plan.md 计划：目标、分工、谁改哪些文件、怎么算做完 tasks.json 任务、依赖、谁在做、状态 events.jsonl 所有事：分派、每一步、提问、回答、合并、花费 agents\前端\ 它收到的提示词、完整过程记录 worktrees\前端\ 它那份代码副本（git worktree，合并完收掉）

为什么都写成文件：项目页就是读这些文件；系统重启、电脑重启以后能接着干；以后想复盘「当时为什么这么做」也翻得到。

宿主原话跟着走：每个干活的任务里都附上你的原话，免得一层层转述走样（调研里 MetaGPT 就栽在这）。

只许改自己的文件：计划里写好谁改哪些文件夹；越界改了，合并时标出来让总指挥决定。

六、需要你拍板的（括号里是默认）

  1. 总指挥用什么模型？（跟主窗口的大脑一样，设置里能单独换成更强的，比如 deepseek-v4-pro）
  2. 每个项目预算多少？（¥30，用到 80% 提醒，用完停下问你；每个项目开工前在计划卡上也能改）
  3. 你能不能直接跟某个智能体说话？（能，但经过总指挥：在项目页底下说，或者点某个智能体「插一句」，总指挥转过去并记进通信）
  4. 做完以后要不要自动把网站跑起来给你看？（不自动，完成卡上有「打开网站」按钮，点了才启动、在系统专用浏览器里打开）
  5. 项目页怎么打开？（项目卡上的按钮；另外托盘菜单、面板加一个「项目」页签列出所有项目，说「打开项目」也行）
  6. 以前的项目还能接着改吗？（能：说「接着改记账网站，加个预算提醒」，总指挥读回计划和记录，出一份新的小计划给你过目）

已经定了的：干活的用哪个智能体在设置里选，默认跟总指挥同一个模型；每个干活的一份 git worktree，总指挥合并；项目文件夹里自动放行，出了文件夹、危险操作照常在主窗口问；预算和轮数有上限；开工前先看计划；项目放哪显示在计划卡上，能弹窗选文件夹，也能直接说；同时最多 12 个，可以改成不限；做完的标准是能启动、测试全过、网站截图检查、评审通过。
